🔑 GitHub-синхронизация

Для автоматической синхронизации данных собак с репозиторием zarmail52/podari_dom нужен GitHub Personal Access Token с правом repo. Токен хранится только в вашем браузере (localStorage). При добавлении, изменении или удалении собаки данные автоматически записываются в файл dogs.json на GitHub.

🐕 Добавить новую собаку

Картинки подтягиваются из папки images/ репозитория zarmail52/podari_dom (ветка main) через GitHub API. Чтобы добавить новое фото — загрузите его в папку images/ репозитория podari_dom на GitHub и нажмите «Обновить список картинок».
